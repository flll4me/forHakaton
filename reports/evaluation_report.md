# Отчёт об оценке Grand Mobile Support Copilot

Сгенерировано `scripts/evaluate.py` 2026-10-30 20:03. Только агрегаты, без текстов обращений.

## Данные и методика

- Валидация: `tickets_valid.jsonl`, 1000 обращений (817 complaint, 183 report). Категорий/приоритетов в данных нет.
- Обучение: только `tickets_train.jsonl.gz` со слабой разметкой (`reports/weak_supervision.md`). Валидация в обучение не входила.
- **Test (основная оценка)**: 100 случайных обращений valid, размечены вручную разработчиком (Claude) по taxonomy.json после завершения настройки; на них ничего не подбиралось.
- **Control v1**: 200 обращений valid (стратифицированы по языку), размечены вручную до обучения; по ошибкам на них дорабатывались правила → оценка оптимистична, приводится для полноты и для разбивки по языкам.
- Ручная разметка — не экспертная разметка Grand Mobile. Accuracy/F1 ниже — оценка, а не результат на истинных метках.
- Приоритет «истины» выводится из ручной категории по критериям taxonomy.json (та же функция, что в сервисе), поэтому macro-F1 приоритета отражает в основном ошибки категории и доказательств.
