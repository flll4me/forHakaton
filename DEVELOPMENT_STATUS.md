## Принятые решения
1. Канонические rule_id: общие правила без префикса (`2.1`), прочие разделы с кодом (`ЖБ 1.2.7`, `GZ 1.1`, `ПГО`, `ОПГ`, `FW`, `ОПЛЗ`, `ПГВД`, `BW`, `FURA`) — номера повторяются между разделами; коды взяты из ответов админов.
2. DM/DB/SK/TK определены только в разделе «RP термины» без номеров → в черновике даётся определение, в `cited` не попадает (без выдуманных номеров).
3. Валидация распределена как скрытый тест (82% жалоб, 12% uz) — используется только для оценки.
4. Поле `lang` шумное (украинский размечен как kk) — не используется как истина; украинский → ответ на ru.
5. cp1251-замены применяются только при признаках казахского (сервер kz, «сильные» символы ќ/ѕ/ј/ѓ, казахские буквы/слова), чтобы не портить украинские є/ї и узбекскую ў. Добавлена `ѓ→ғ` (визуальный двойник ґ).
6. Приоритет — детерминированная функция по критериям taxonomy.json (меток нет). Противоречие «жалобы с доказательствами = p1» vs пример контракта (оскорбление со скринами = p2) решено в пользу конкретных категорий: insult/dm → p2 (p3 без доказательств), cheat/scam/rmt → p1, admin/other с доказательствами → p1.
7. needs_human=true для всех жалоб, требующих решения о наказании (как в примере контракта), для платежей/аккаунта/апелляций/взлома всегда; автоматически отвечаемые — оффтоп, невалидные жалобы, помощь с машиной (эвакуатор), вопросы с уверенной цитатой.
8. LLM по умолчанию выключен (`LLM_PROVIDER=none`; общий выключатель `LLM_ENABLED`); рекомендуемая модель claude-haiku-5-5 (лимит $0.002/обращение); ответ LLM проходит те же проверки, иначе шаблон. Реальные вызовы LLM не выполнялись (нет API-ключа) — ветка проверена подставными провайдерами и SDK, направленным на локальный сервер-имитатор (таймаут, 4xx/5xx, битый ответ).
10. Дополнительные условия эскалации (аудит): угрозы вне игры; запрос снятия наказания/возврата при любом порядке слов; complaint.invalid с упоминанием наказания.
9. Порог MIN_CATEGORY_CONFIDENCE=0.55 — по таблице порогов на control v1.

## Обнаруженные и исправленные ошибки
- Катастрофический бэктрекинг regex `CONTENT_FREE_RX` (prepare_dataset > 10 мин) → заменён на токенный разбор (21 с).
- Рекурсия в раскрытии сленга BM25; стемминг усечением не сводил «сайтов/сайты» → отсечение окончаний.
- Раздел «Правила войны за бизнес» не сопоставлялся с кодом (несовпадение строки) → сопоставление по ключевому слову.
- `REFUND_RX` срабатывал на «пере**верните машину**» → граница слова.
- Нерелевантные цитаты (GZ/5.4 к обычному DM, 2.4 к «оск родни») → проверка применимости пункта по тексту.
